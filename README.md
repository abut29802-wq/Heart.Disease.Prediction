# Heart Disease Prediction

A machine learning project for predicting the presence of heart disease based on patient health-related attributes.

## Project Overview

This project demonstrates a machine learning workflow for heart disease prediction using a structured medical dataset. The project includes data preprocessing, exploratory analysis, model training, and evaluation.

The current implementation is based on an existing open-source project and is being extended and organized for educational and assessment purposes.

## Features

- Data preprocessing and cleaning
- Exploratory data analysis
- Machine learning-based heart disease prediction
- Model evaluation
- Dataset included for reproducibility
- Jupyter Notebook-based implementation

## Technology Stack

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
